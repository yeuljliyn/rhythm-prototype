# 2026-07-25 개발일지

## Stage1 콜/리스폰스 — Hand/Ants/Boss 애니메이션 연동

- `CallDirector`에 이벤트 3개 추가: `OnPhaseChanged`(Boss1↔Boss2 전환용), `OnCallCue`(콜 박자마다 발화), `OnResponsePress`(플레이어가 버튼 누를 때마다 발화, 판정 성공 여부 무관).
- `Stage1WaterPourVisuals` 신규 작성 — Hand/Ants/Boss는 자유 루프 안 하고, 이벤트가 올 때만 현재 애니메이터 상태를 프레임 0부터 1회 재생("펄스")한 뒤 다시 정지. Hand는 `OnCallCue`(콜 박자)에, Ants는 `OnResponsePress`(플레이어 클릭)에 반응 — 처음엔 "리스폰스 구간이면 Ants 자동 루프"로 만들었다가, 사용자 피드백으로 "개미는 플레이어가 실제로 클릭할 때만 움직여야 한다"는 걸 반영해 다시 설계함.
- 손 애니메이션이 계속 안 움직이는 버그 → 원인은 `Time.timeScale`이 이전 플레이 세션(다른 씬의 일시정지/결과화면)에서 0으로 남아있던 것. `CallDirector`/`CallClock`은 dspTime 기반이라 timeScale 영향을 안 받아 판정 로직만 보면 멀쩡해 보이는 함정이 있었음. `CallClock.Awake()`에서 `Time.timeScale = 1f`로 리셋해서 해결(`RhythmManager`에 이미 있던 동일한 방어 로직과 같은 패턴).

## 일시정지 버그 수정

- 일시정지 중에도 "미스" 판정+효과음이 계속 발생하는 버그 발견. 원인은 `CallDirector.Update()`가 `Time.timeScale`과 무관하게 매 프레임 계속 돌면서 dspTime 기준 마감을 계속 체크했기 때문.
- `CallClock`에 진짜 `Pause()`/`Resume()` 추가 — 멈추는 순간의 `SongTime`을 얼려서 반환, 재개 시 멈춰 있던 시간만큼 내부 기준 시각을 밀어서 시간이 안 튀게 함.
- `CallDirector.Update()`에 `if (clock.IsPaused) return;` 가드 추가.
- `Stage1PauseMenuManager`가 오디오를 직접 만지지 않고 `CallClock.Pause()/Resume()`을 통해서만 제어하도록 변경.

## 결과창 / 일시정지 UI — BattleScene 스타일 재사용

`Stage1Scene`이 이제 `BattleScene`을 대체하는 배틀씬 역할(단, `BattleScene`은 삭제하지 않고 레거시로 보존).

- `Stage1ResultScreen` — `BattleResultScreen`과 동일한 스프라이트 에셋(팝업/랭크텍스트/랭크S~C/화살표 등) 재사용, 절차적으로 팝업 생성. 단일 페이지만(스테이지 해금/무구 경제는 아직 Stage1Scene에 안 붙어 있어서 생략), 화살표는 항상 LobbyScene으로.
- `Stage1PauseMenuManager` — `PauseMenuManager`와 동일한 ESC 토글/3-2-1 리줌 카운트다운/CONTINUE·SETTINGS·RETRY·LOBBY 버튼.
- 공유 인프라 `SettingsManager`만 최소 확장(ESC 핸들러가 `Stage1PauseMenuManager`도 인식, 오디오 탐색 폴백 추가) — `BattleScene` 파일 자체는 안 건드림.
- 기존 플레이스홀더 `Stage1ResultUI.cs`는 완전히 대체되어 삭제.

## 기획서 반영 — 스테이지 내장 튜토리얼 (물타기만 우선 적용)

기획서 핵심 변경: 별도 튜토리얼 씬(`TutorialIntroScene → TutorialBattleScene → TutorialClearScene`) 없애고, 스테이지 씬 하나 안에서 튜토리얼(앞) → 본편(뒤)이 로딩·암전 없이 이어지는 구조로 전환. 기존 튜토리얼 씬 3개는 삭제하지 않고 그대로 둠(참조하는 곳이 많아서). 이번엔 물타기(Stage1Scene)에만 적용 — 파도타기는 신규 미니게임이라 아트/차트가 없어서 보류.

- `Stage1DialogueScene.unity` + `Stage1DialogueSceneManager.cs` — 기존 `DialogueScene`을 복제(원본 안 건드림)해서 §0 오프닝(사이버 신당, 잭두-신령님 첫 만남) + §1 물귀신 등장 대사를 새로 채움. §0→§1 전환 시 배경도 자동으로 바뀜(신규 `Node.BgKey` 필드). 끝나면 `Stage1Scene`으로 전환.
- `Stage1_Tutorial.asset` — `Stage1_MVP_Test`를 복제한 튜토리얼 전용 차트. 같은 음악/BPM(템포를 늦추지 않음, 기획서 요구사항), 간단한 콜-리스폰스 8세트를 넉넉하게 반복 배치.
- `Stage1TutorialGate.cs` — 튜토리얼→본편 전환 오케스트레이터. `TutorialDirector`(튜토리얼 차트)와 `Director`(본편 차트) 두 벌의 `CallClock`/`CallDirector`를 두고, 처음 진입 시엔 튜토리얼만 돌리다가 Hit 3번 쌓이면 본편으로 전환(점수 리셋 포함, 씬 전환 없음). 재도전 시엔 `PlayerPrefs` 플래그로 튜토리얼을 건너뜀.
- `CallDirector.StartsInResponsePhase` 프로퍼티 + `Stage1WaterPourVisuals.BindDirector()` 런타임 재바인딩 추가 — Hand/Ants/Boss 비주얼이 튜토리얼→본편 전환 시 director를 갈아끼워도 계속 정상 동작하도록.
- 개발 중 실제 버그 발견: "이미 튜토리얼을 봤음" 분기에서 튜토리얼 GameObject를 끄는 걸 빼먹어서 튜토리얼+본편이 동시에 켜져 있던 문제 → 수정.
