# 2026-08-05 개발일지

## Stage1DialogueScene — 런타임 절차 생성 UI를 에디터 오브젝트로 전환

`Stage1DialogueSceneManager`가 원본 `DialogueSceneManager`를 포크하면서 `BuildUI()`/`BuildVoice()`로 Canvas 전체(배경/캐릭터/대사창/선택지/EventSystem/음성 AudioSource)를 `Start()`에서 코드로 절차적으로 생성하는 패턴까지 그대로 가져왔다는 걸 지적받음 — "오브젝트는 에디터에서 바로 보이게" 컨벤션 위반. Play를 눌러야만 Hierarchy에 뭔가 보이는 상태였음.

- `Canvas → BG/Line/CharA(+NameA)/CharB(+NameB)/DialogueBox(SpeakerName/DialogueText/Prompt/SkipHint/ChoicePanel(Choice0·1+BtnText))`, `EventSystem`, `DialogueManager/[DialogueVoice]` 전부 MCP 도구로 씬에 실제 GameObject로 배치.
- 스크립트에서 `BuildUI()`/`BuildVoice()`/`Anchored()`/`Stretch()`/`MakeTMP()` 전부 제거, 해당 UI 참조는 `[SerializeField]`로 교체하고 씬에서 직접 와이어링.
- 이 과정에서 실제 버그 하나 발견: `Canvas` 컴포넌트에 `renderMode`를 명시적으로 `ScreenSpaceOverlay`로 안 찍어서 기본값(`WorldSpace`)으로 남았고, 그 결과 게임뷰엔 카메라 배경색(파란 단색)만 뜨고 UI가 전혀 안 보이는 상태였음. `CanvasScaler` 프로퍼티는 다 챙겼는데 `Canvas.renderMode` 자체를 빼먹은 게 원인 — 발견 후 바로 수정.

## SFX 큐 노트 에디터 신규 추가 — 콜/리스폰스와 완전히 별개 시스템

기획자가 리듬 노트를 찍어서 원하는 위치에 효과음만 재생하고 싶다는 요청. 기존 `CallPatternData`(콜/리스폰스, 판정 있음)와는 성격이 달라서 — "그냥 소리만 재생되는 것", 판정도 입력도 없음 — 완전히 새 에셋 타입 + 새 에디터 창으로 분리해서 작성. 기존 Call Map Editor는 손대지 않음.

- **`SfxCuePatternData`**(`Assets/Scripts/Data/`): 플랫한 `SfxCueEntry`(`line` 0~3 = Q/W/E/R, `beat`, `clip`) 리스트. `keySlots`(Q/W/E/R → 현재 지정된 효과음)도 에셋에 같이 저장해서 에디터 재시작해도 매핑 유지. 핵심 요구사항: 노트는 찍히는 순간 그 키에 걸려있던 clip을 **복사해서** 저장 — 나중에 키 슬롯을 다른 소리로 바꿔도 이미 찍힌 노트는 안 바뀌고, 그 뒤로 찍는 것부터만 새 소리로 찍힘.
- **`SfxCuePlayer`**(런타임): 자체 재생 스케줄을 갖지 않고 이미 돌고 있는 `CallClock`의 `SongTime`을 그대로 따라가며 박자가 되면 `AudioSource.PlayOneShot`만 호출. 판정/입력 관여 없음, 곡이 일시정지돼도 어긋나지 않음.
- **`Stage1SfxCueEditorWindow`**(`RhythmGame → Sfx Cue Editor`): Q/W/E/R 4개 고정 라인, REC 모드에서 곡 재생 중 Q/W/E/R을 누르면 그 순간 박자에 스냅해서 스탬프. 편집 모드는 클릭=추가/드래그=이동/우클릭=삭제, Del=선택 삭제. 4라인이라 같은 박자에 여러 개 겹쳐 찍는 것도 자유로움.

### REC 중 오디오 피드백 시도 — 결국 무음으로 되돌림

노트 찍는 도중에 지정한 효과음이 실제로 들리면 좋겠다는 요청이 있었음. 확인해보니 Unity 에디터의 프리뷰 오디오 API(`UnityEditor.AudioUtil`)는 리플렉션으로 까본 결과 전역 재생 슬롯이 딱 1개(`PlayPreviewClip`/`IsPreviewClipPlaying`/`GetPreviewClipPosition` 전부 단수형) — Play 모드 없이는 곡과 효과음을 진짜로 겹쳐 재생할 방법이 없음. Play 모드로 전환하는 방안은 현재 열려있는 씬이 통째로 같이 실행돼버리는 부작용이 있어서 기각.

대안으로 "스탬프 순간 곡을 잠깐 끄고 효과음 재생 후 정확한 샘플 위치로 곡 이어붙이기"(duck-and-resume)를 구현했었으나, 실제로 써보니 음악이 중간에 끊기는 게 어색하다는 피드백 → 전부 되돌리고 REC는 처음처럼 무음 스탬프로 복귀. 개별 노트 확인용 "▶ Play" 버튼(편집 모드, 선택된 노트 한정)만 남김.
