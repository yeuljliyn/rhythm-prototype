# rhythm-prototype 기획 문서

기계 무당 잭두가 플레이어(신령님)의 박자를 빌려, 주식에 물려 죽은 물귀신을 다섯 판 놀아드리고 배에 실어 보내는 콜-리스폰스 리듬 게임.

## 세계관

- 부족한 것: 돈과 시간. 잭두는 내림굿 할부를 다음 달까지 못 넣으면 고철로 압류된다. 물귀신은 9만 원에 물려 팔 때를 놓친 채 죽었다.
- 금지된 것: 귀신을 이기거나 쫓는 것. 쫓으면 화내고 돌아온다. 끝까지 같이 놀아드려야 간다.
- 영감놀이의 방법(2026-09-30 추가): 영감이 씌인 이의 **무리로 변해서** 같이 놀아주다 보낸다(파묘의 도깨비놀이에서 착안). 물귀신의 무리는 개미라 잭두는 **개미로 변신**한다. 변신은 연기가 잭두를 감쌌다 걷히면 개미 잭두가 서 있는 것으로 보여주고, 대사로 설명하지 않는다. 게임에서 플레이어 개미(1-1의 5번째 개미, 1-2 릴레이의 마지막, 1-4의 내 개미)가 잭두인 이유.
- 개미 몸은 스스로 안 움직인다. 신령님의 장단에만 움직인다. 화면 규칙("캐릭터는 이벤트 없인 정지")이 곧 설정. Miss는 개미 잭두가 삐끗한 것.
- 개미 잭두도 말은 하되 **초상화 없이 말풍선으로만**. 초상화 잭두가 나오면 사람 모습으로 돌아온 것. 이 구분이 화면만으로 "굿판 안/밖"을 알려준다.
- 충돌: 잭두(보내야 산다) ↔ 물귀신("안 가, 존버는 승리한다") ↔ 개미들(물귀신 따라 들어와 같이 잠긴 것들, 물귀신 없이는 못 나감).
- 플레이어의 위치: 화면 밖 신령님. 초상화 없음, 대사는 선택지로만. 박자를 넣어주는 존재.
- 톤: 사이버 신당, 폐허 증권거래소, 광대 분장. 레퍼런스는 리듬천국(입력 구조), 한국 굿(순서극), 주식 커뮤니티 은어(파도타기·넘기기·존버·물타기).
- 플레이어가 세계를 알게 되는 방식: 대사 씬 §0·§1(§1은 변신으로 끝남) → 플레이 → 결과 뒤 사람 잭두의 보고(판 후 대사). 인트로 씬은 연출만, 글 없음. 판 전 대사는 두지 않는다. 물귀신은 판을 넘길 때마다 한 단계씩 풀린다. 상세는 `## 구조 > 서사 전달`.

## 메커니즘

- 핵심 동사: **따라 치기**(콜 → 리스폰스). 버튼 하나, Tap/Hold, Hit/Miss.
- 코어 루프: 캐릭터가 리듬을 보여줌 → 같은 리듬으로 따라 침 → 캐릭터가 즉시 반응(스프라이트 스왑/펄스) → 곡 끝 랭크.
- 긴장: 콜이 시간상 겹침(룩어헤드), Hold 조기 이탈은 즉시 미스, 1-2는 여러 잔이 동시에 돎.
- 변주 축: 콜 대 리스폰스 개수(4:1, 5:1, 1:1), Tap/Hold, 겹침 밀도.

## 구조

### 진행

첫 실행: `StartScene → §0 오프닝 → §1 물귀신(끝에 변신) → 1-1 인트로 → 1-1 연습 → 본편 → 결과창 → 판 후 대사 → 지하 로비(첫 등장)`. 로비는 고를 게 생긴 뒤에 나온다.
두 번째 실행부터: `StartScene → 지상 로비 → 지하 로비 → 1-N 인트로 → 연습 → 본편 → 결과창 → (S/A 첫 클리어면) 판 후 대사 → 지하 로비`. S/A 랭크면 다음 판 해금.

| 판 | 이름 | 주식 은어 | 미니게임 |
|---|---|---|---|
| 1-1 | 파도타기 | 추격매수 | 개미 4마리 손 들면 5번째가 나 |
| 1-2 | 넘기기 | 물량 떠넘기기 | 잔 릴레이, 마지막이 나 |
| 1-3 | 버티기 | 존버 | 물속에서 Hold, 숨 쉴 때 release |
| 1-4 | 물타기 | 물타기 | 큰손이 붓는 대로 따라 붓기 |
| 1-5 | 이별이여 작별이여 배 놓아가자 | 손절/보내기 | 1-1~1-4 리믹스. 영감 굿노래 발췌 |

### 서사 전달 (2026-09-30 방향 B·변신판 확정)

**진단(유지).** 몰입이 깨지는 원인: 대사가 코어 루프 밖에 있음 / 선택지가 가짜 질문 / 대사 중 아무 일도 안 일어남 / 물귀신의 변화가 5판 사이에 없음. 여기에 하나 더: **첫 플레이까지 씬 로드 6번**(§0 → 지상 로비 → §1 → 지하 로비 → 인트로 → 게임). 로비 두 개가 첫 플레이 전에 끼어 흐름을 끊는다.

**원칙.**
- 대사 씬은 §0·§1 둘뿐. 그 뒤로 잭두가 초상화로 말하는 자리는 결과창 뒤 보고 하나.
- "왜 개미인지"는 §1 끝 변신 장면 하나로 보여준다. 설명 대사 없음.
- 인트로 씬은 지금 연출 그대로, 글자 없음(캡션·판 전 대사 모두 철회).
- 선택지는 신령님의 태도 두 축(냉소/호기심), 잭두의 다음 대사만 갈린 뒤 합류. "저게 뭐야?"형 금지.
- 물귀신 아크(5박자): 안 가(§1) → 남 따라 탄 걸 인정(1-1 후) → 개미를 알아봄(1-2 후) → 존버가 약해짐(1-3 후) → "…팔걸"(1-4 후) → 배(1-5 후).

**§0 오프닝 (7노드, 구현됨).** 잭두 소개 → 캔 → "굿은 장단, 박자를 넣어주셔야" → 첫 손님. 문구는 `DialogueSceneManager`.

**§1 물귀신 등장 (5노드 + 변신, 구현 일부).** 9만 층 → 주식 → 선택(쫓아내? / 어떻게 보내는데.) → 놀아드리는 굿 → "안 가!" → 잭두 "기운은 좋으시군요. 저 정도면 잘 노시겠습니다." → **변신**: 잭두 초상화가 연기에 감싸이고, 걷히면 개미 잭두. 물귀신은 그걸 보고도 개미 하나 더 늘었다고만 여긴다(반응 없음 또는 "...개미 또 왔네"). 이 화면이 그대로 1-1 인트로로 이어진다(첫 실행). 변신 뒤 잭두 대사는 없다 — 다음 말은 1-1 연습 첫 캡션(개미 잭두 말풍선) "저는 이제 못 움직입니다. 신령님이 쳐 주셔야 합니다."

**판 중.** 개미 잭두 말풍선(`Stage1SpeechBubble`) — 연습 캡션 3개가 그 자리. 물귀신은 판마다 그 판의 행동을 외친다(1-1 "파도 온다! 다들 타!", 1-3 "안 팔아! 존버는 승리한다!"). 이건 대사가 아니라 스테이지 연출(효과음/말풍선)로.

**결과창 뒤 보고 (판 후 대사, 구현됨).** 한 판 놀고 난 뒤 물귀신이 넋 놓은 틈에 연기 → 사람 잭두로 돌아와 신령님에게 보고. 물귀신은 혼잣말처럼 흘린다. 그 판 무대 위 오버레이(`Stage1PostDialoguePanel`). S/A 첫 클리어 시 1회. 문구는 아래 표.

| 판 | 결과창 뒤 보고 |
|---|---|
| 1-1 | 물귀신(슬픔) "...그때 다들 손 들길래." / 잭두 "타셨죠. 다들 탈 때." / 물귀신(분노) "그래도 안 팔아." |
| 1-2 | 물귀신(일반) "...쟤들 왜 여기 있어." / 잭두 "저 양반 따라 들어왔다가 같이 잠긴 것들입니다. 저 양반 없이는 못 나갑니다." / 선택: 냉소 "지 탓이네." → "...그렇게 되죠." / 호기심 "같이 보낼 수 있어?" → "저 양반이 가면 따라갑니다." |
| 1-3 | 물귀신(슬픔) "존버는... 승리..." / 잭두(슬픔) "남 일 같지 않습니다. 저도 다음 달까지 못 넣으면 저 옆자리입니다. 사람은 신용불량자가 되지만 저는 고철값입니다." / 선택: 냉소 "너도 물렸네." → "...물렸죠." / 호기심 "그래서 더 잘 보내야겠네." → "그래서 더 잘 보내드려야 합니다." |
| 1-4 | 물귀신(일반) "이 분장... 내가 한 거 아닌데." / 잭두 "도깨비입니다. 재물신이죠. 부자로 만들기도 하고 저 꼴로 만들기도 합니다." / 잭두(화남) "좇던 대박이 도깨비불이었던 겁니다." / 물귀신(슬픔) "...팔걸." |
| 1-5 | 물귀신(웃음) "...개미들은. 같이 가자." / 잭두(웃음) "잘 가셨습니다." / 선택: 냉소 "그래서 수금은." → 잭두(슬픔) "...정산은 넘겼습니다. 이번 달은." / 호기심 "캔은 면했어?" → 잭두(웃음) "면했습니다. 이번 달은." / 공통 "다음 손님이 와 계십니다." |

**인트로 등장 (2026-09-30 확정: 연기 와이프 + 타이틀 지연).** 판에 들어갈 때는 검정 페이드 대신 **연기 와이프**: 연기가 화면을 덮었다 걷히며 인트로가 드러난다. §1 변신 때 잭두를 감싼 연기가 그대로 화면을 덮어 1-1 인트로로 이어지고, 로비에서 판을 고를 때도 같은 연기로 들어간다. "판에 들어간다 = 개미로 변해 들어간다"를 매번 화면이 말한다. 인트로 씬 안에서는 배경이 먼저 보이고 **타이틀 이미지는 0.7초 뒤 페이드인**(살짝 커지며), IntroBGM도 같이 페이드인. 인트로 연출 자체(양동이·수조·풍선 등)는 지금 것 그대로. 연기 스프라이트는 절차 생성(부드러운 뭉치 텍스처 + 퍼프 시트)으로 새 아트 없이.

**첫 플레이까지의 흐름.** 첫 실행은 로비를 건너뛴다: §0 끝 "첫 손님이 와 계십니다" → §1 → 변신 → 1-1 인트로 → 연습. 지상·지하 로비는 1-1 결과·보고 뒤에 처음 나온다. 두 번째 실행부터 지금 흐름. 씬 로드 6번 → 3번.

**철회된 것.** 판별 인트로 한 줄 캡션(인트로엔 글 안 넣음). 판 전 대사 씬 `Stage1PreDialogueScene`(변신한 잭두가 물귀신 앞에서 설명을 늘어놓는 게 설정과 충돌) — 코드에서 제거할 것. 탈(가면) 해석 — 변신으로 확정.

**기각된 안.** 굿의 거리로 판 이름 재프레이밍(영감이 이미 들어와 있어 안 맞음). 지하 로비 구멍 속 물귀신 그림 교체(새 아트). 대사씬을 콜-리스폰스로(대사 매니저 신규 + 읽기/치기 충돌). 대사씬 삭제(굿 규칙을 알려줄 자리가 없음). 매 판 인트로에 변신 반복(인트로 연출은 지금 것을 살리기로).

## 프로토타입 스펙

- 가설: §1 끝 변신 장면 하나로, 설명 대사 없이 "플레이어 개미가 잭두"라는 게 전달된다. 그리고 첫 실행에서 로비를 건너뛰면 첫 플레이까지의 몰입이 유지된다.
- 최소 요소: §1 마지막에 변신 연출(잭두 초상화 → 연기 → 개미 잭두 스프라이트, 1.5초) + §1 완주 후 첫 실행이면 1-1 인트로로 직행 + 판 전 대사 제거 + 1-1 연습 첫 캡션 문구 교체. 판 후 대사는 이미 있음.
- 성공 판단: 처음 하는 테스터가 1-1을 치고 나서 "내가 움직인 개미가 누구냐"에 잭두라고 답하면 성공. 첫 플레이까지 "언제 게임 시작해?"를 묻지 않으면 성공.
- 실패 신호: 변신을 못 알아봄 → 연기 시간을 늘리고 §1 마지막 잭두 대사를 "…잠깐 섞여 들어가겠습니다."로 예고. 로비를 건너뛴 게 어색함 → §1 뒤 "지하로 내려가는" 3초 연출 추가.

## 미정

- 연기 와이프의 길이(덮는 0.5초 / 걷히는 0.8초 정도)와 로비→인트로에서도 연기 소리를 넣을지.
- 변신 직후 물귀신 반응: 무반응 vs "...개미 또 왔네" 한 마디.
- 결과창 뒤 보고 앞에 "연기 → 사람 잭두" 역변신 연출을 넣을지(없으면 초상화가 그냥 뜸).
- 판 중 물귀신 외침("파도 온다!")을 어느 판까지 넣을지, 말풍선인지 효과음인지.
- 인트로 → 스테이지 씬 전환도 연기로 갈지, 지금 검정 페이드로 둘지.
- 잭두 문체(존댓말)·물귀신 문체(반말) 유지. 문구는 전부 초안.
- 클리어/해금 기준: 현재 코드는 S/A 해금. B 클리어 논의는 구 무구 경제 기준이라 폐기.
